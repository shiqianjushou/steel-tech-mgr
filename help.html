INSTALL & SAFETY

安装与安全说明

从下载到运行的全部注意事项：浏览器提示、SmartScreen、杀毒软件误报的处理方法，以及常见问题解答。

一、安装步骤

  1. 在「软件下载」页点击下载安装包（约 174 MB），保存到电脑任意位置。
  2. 双击运行 Setup-steel-tech-mgr-1.0.0.exe，按提示点击「下一步 / 安装」。
  3. 安装完成后软件自动启动，进入试用或激活流程。
  4. 新用户：试用期为 30 天，直接点击「进入软件」即可使用。
  5. 试用到期后需激活：在激活窗口复制机器码，联系开发者获取授权码后粘贴激活。

二、下载与运行时的系统提示（正常现象，可放心通过）

以下提示是 Windows 和浏览器对所有未签名软件的统一提醒，并非病毒告警：

提示场景 提示内容 正确操作
浏览器下载 此类型的文件可能损害你的计算机 点击「保留」继续下载
Windows 首次运行 Windows 已保护你的电脑 / 未知发布者 点「更多信息」→「仍要运行」
杀毒软件（360 / 火绒 / 腾讯管家等） 风险程序 / 未知文件拦截 选择「信任 / 允许运行」，并加入白名单

说明：本软件未经第三方数字签名，因此会有以上提示；这不会影响使用。我们也在持续优化兼容性，降低误报概率。

三、把软件加入杀毒软件白名单（推荐，一劳永逸）

安装完成后，将软件目录加入杀毒软件信任区，之后启动就不会再被拦截：

  • 安装版默认目录：C:\Users\你的用户名\AppData\Local\Programs\钢结构技术管理系统
  • Windows Defender：设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护 → 排除项 → 添加该文件夹
  • 360 / 火绒 / 腾讯管家：打开「信任区 / 白名单」，添加上述文件夹

四、常见问题

  • 下载速度慢或无法下载？ 受网络环境影响，可换网络重试，或联系开发者获取网盘备用下载。
  • 双击安装包没反应？ 右键 → 以管理员身份运行；或确认杀毒软件未拦截。
  • 安装后打开软件弹出激活窗口？ 正常流程：新用户为 30 天试用，可直接使用；试用结束需激活。
  • 如何获取授权码？ 激活窗口复制机器码，微信联系开发者，通常当日回复。
  • 软件会不会破坏我的数据？ 不会。软件只写用户数据目录（%APPDATA%），重装、卸载、更新均不会删除您的工程与配置。
