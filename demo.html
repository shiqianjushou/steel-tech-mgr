DEMO

软件演示

六大核心模块逐一介绍。以下为功能示意，实际界面以软件内为准（可在激活试用后运行软件查看真实界面）。

MODULE 01

材料分析与构件清单

导入材料分析表 / Tekla 报表 Excel，自动识别二进制 .xls 与文本伪 .xls，按标题自动归类零件。生成构件清单后可编辑、搜索筛选，并与参考表对比替换。

  • 真正的二进制 .xls 与 GBK 文本 .xls 双兼容导入
  • 参考表替换：差异预览、原表 / 参考双列对照
  • 数据校验：重量为 0、编号不连续、数量不一致标色提示
MODULE 02

板材预提料与采购计划

按定尺 / 非定尺模式自动提料，匹配现货产品库，规格网格搜索最优组合，按品种合并生成采购计划表。

  • 定尺 / 非定尺提料，现货产品库智能匹配
  • 规格网格搜索，面积 / 重量 / 金额 / 利用率一键计算
  • 采购计划表 Excel 导出
MODULE 03

排料（套料）引擎

ironnest 与 pyckingsolver 双引擎可选，直条 / 方形 / 异形零件排样，支持裁断拼接，实时计算利用率。

  • 引擎可切换，裁断 / 拼接策略自由组合
  • CAD 式交互排样编辑器，零件拖放调整
  • 板材使用计划表与 NC1 零件匹配
MODULE 04

人工核算（材料核价法）

零件按材料分析表列结构自动分类板材 / 型材 / 外购，板材单价 = 基准价 × 板厚系数 × 面积系数，型材单价 = 基准价 × 规格系数 × 长度系数。

  • 板厚 / 面积 / 规格 / 长度系数曲线可自定义增删
  • 备注含「成品 / 外购」自动识别为外购件
  • 按构件汇总人工费，零件明细弹窗逐项核对
MODULE 05

油漆核算

涂层方案（底 / 中 / 面漆）逐层设色，损耗系数按截面库曲线，内置劳尔 RAL 与国标 GSB05 全系列色卡，支持在线更新色库。

  • 每层可单独设色，明细表按构件覆盖涂装颜色
  • 色卡号自动补色，取色器双向联动
  • 「是否涂装」按构件控制，用量随涂装状态联动
MODULE 06

Tekla 报表导入与导出

内置 3 套模板识别规整，自动拆分 PL 型材、换算面积，生成构件 / 散件清单、材料计划与板材 / 型材零件计划。

  • 3 模板（A / B / C）自动识别与规整
  • 构件 / 散件清单、材料计划、零件计划全覆盖
  • Excel 原子写导出，格式与软件内一致
